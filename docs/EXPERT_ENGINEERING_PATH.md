# Expert Engineering Path

The repository is designed to move through four modes.

## 1. Guided implementation
You receive complete theory, small steps, tests and a reference solution. The objective is accurate mental models.

## 2. Specification-driven implementation
The exercise stops telling you the exact code. You receive a specification section, test vectors and acceptance criteria. You design the implementation.

## 3. Existing-code archaeology
You build and inspect a mature project, trace a subsystem, locate a bug or behavior, write a regression test and make a constrained change.

## 4. Original engineering/research
You formulate a problem, select baselines, implement alternatives, measure them, document limitations and make a defensible conclusion. Some work should eventually be submitted upstream or used by others.

A portfolio becomes strong when it contains evidence from all four modes, not only guided exercises.
