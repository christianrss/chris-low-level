# Specification Reading Map

Use official specifications/manuals as the primary source whenever a milestone reaches the relevant level.

- x86-64: Intel/AMD architecture manuals.
- ARM64: Arm Architecture Reference Manual.
- RISC-V: unprivileged + privileged ISA specifications.
- ELF: System V ABI + architecture supplements.
- PE/COFF: Microsoft PE/COFF specification.
- UEFI: UEFI specification + PI specification when firmware phases are introduced.
- ACPI: ACPI specification.
- PCIe: public architectural material plus device documentation available for the lab hardware.
- USB/HID/UVC: USB-IF class/protocol specifications.
- NVMe: NVM Express specifications.
- virtio: OASIS virtio specification.
- terminals: ECMA-48 and relevant de-facto terminal behavior documents.
- HTTP: current IETF HTTP specifications.
- SSH: IETF SSH RFC family and OpenSSH protocol notes.
- DNS: IETF DNS RFCs.
- BitTorrent/DHT: protocol specifications and BEPs.

For proprietary or NDA-only hardware details, do not invent missing register behavior. Use virtual/open devices or published documentation.
