# Day 01 consolidated benchmark baseline

These values were collected while validating the generated repository. They are **container baselines**, not performance claims about the user's machine. Re-run them on the target machine before publishing comparisons.

## Validation environment

- CPU: AMD EPYC 9V74 80-Core Processor
- OS/kernel: Linux 6.18.35 x86_64
- C/C++ compiler: GCC/G++ 14.2.0
- Python: 3.13.5
- CMake: 3.31.6
- Native build type: Release

## Interpretation

The purpose of Day 01 is to establish **reproducible baselines and teach methodology**, not to advertise impressive numbers. Several benchmarks deliberately expose confounders that future exercises will remove. For example, process-startup cost contaminates the VM/disassembler measurements, while the terminal and HTTP measurements omit real I/O.

A strong portfolio entry should preserve the baseline, change one controlled variable, record the environment and explain why the result moved. Do not compare results from different machines as if software alone caused the delta.

## Reproduce

```bash
python scripts/run_all_benchmarks.py
```

Record local CPU, OS, compiler flags, input size, warm-up policy and repetitions before publishing any before/after result.
