# Day 01 — versão corrigida após auditoria pedagógica

Esta é a versão corrigida do Day 01 (03/09/2026), criada após a identificação de divergências entre algumas resoluções guiadas e seus respectivos starters.

## O que foi corrigido
- Os 13 módulos do Day 01 foram auditados.
- 45 TODOs pedagógicos foram mapeados entre `starter`, `RESOLUCAO_GUIADA_PASSO_A_PASSO.md`, `TESTES_GUIADOS.md` e `solutions`.
- Cada módulo possui `PESQUISA_GUIADA.md`.
- `graphics/dual_backend_3d` foi refeito para que rasterização, Lambert, câmera, `look_at`, input/câmera e culling tenham pontos concretos no starter e correspondência na resolução.
- Foi adicionado `scripts/pedagogy_check.py` para validar automaticamente a correspondência pedagógica.

## Fonte autoritativa para realizar as atividades
Use os arquivos de cada módulo nesta ordem:
1. `TEORIA_PASSO_A_PASSO.md`
2. `PESQUISA_GUIADA.md`
3. `RESOLUCAO_GUIADA_PASSO_A_PASSO.md`
4. `starter/`
5. `TESTES_GUIADOS.md`
6. `solutions/` somente para conferência/gabarito.

O arquivo `VALIDATION_DAY01.md` registra a auditoria executada.

## Importante sobre o DOCX mestre
O DOCX mestre histórico foi produzido antes desta auditoria e foi removido deste pacote corrigido para evitar que você siga instruções desatualizadas. Os arquivos Markdown de cada módulo são a fonte autoritativa e mais recente desta versão.
