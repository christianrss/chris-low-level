# Pesquisa guiada — Linux distro: pacote próprio + rootfs reproduzível

Fontes para leitura dirigida:
- kernel.org — confirme qual release stable está ativa e diferencie mainline/stable/LTS.
- `man 7 hier` — pesquise a finalidade histórica dos diretórios do filesystem Linux.
- BusyBox FAQ/documentação — descubra por que BusyBox é útil como bootstrap de rootfs mínimo.
- pesquise “initramfs cpio kernel documentation” e responda: por que um diretório rootfs de staging ainda não é um initramfs?

## Regra
Use as fontes para **entender e validar**. Não copie uma implementação pronta para preencher o starter. Registre em poucas linhas o que aprendeu e qual decisão do exercício a fonte ajuda a justificar.
