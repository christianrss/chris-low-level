# Benchmarks

Root-level benchmark results are snapshots, not universal rankings.

For every result record:
- git commit/tag;
- CPU/GPU;
- RAM if relevant;
- OS/kernel;
- compiler/runtime + version;
- optimization flags;
- input size/data;
- warm-up;
- repetitions;
- metric definition;
- raw samples or a small machine-readable summary;
- interpretation and known confounders.

Prefer medians/distributions over a single number for noisy workloads. Do not compare different machines as if the delta were caused only by code.
