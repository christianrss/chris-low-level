# Starter — Arena Allocator e alinhamento

Use `projects/chris-arena` apenas como solução depois da tentativa.

1. Recrie a API descrita na teoria.
2. Escreva primeiro um teste nominal e um edge case.
3. Implemente o caminho mínimo para fazê-los passar.
4. Adicione validação de erro.
5. Só então compare com `solutions/`.

O starter é deliberadamente documental para evitar entregar a resposta dentro do mesmo arquivo que você deve completar.
