# Research note template — use after benchmarks

Copy to `research/YYYY-MM-DD-<module>.md` when completing the **Desafio** exercise.

```markdown
# Research — <module> — YYYY-MM-DD

## Hypothesis
What did you expect before measuring?

## Environment
- OS, CPU, compiler/runtime, flags
- Input sizes and warm-up protocol

## Raw results
| Run | Metric | Value |
|-----|--------|-------|
| 1   |        |       |

## Median / summary


## Conclusion
Was the hypothesis confirmed? What would you try next?

## Regression risk
What test would catch a future performance or correctness regression?
```

See [`research/README.md`](../research/README.md) for the standard experiment shape.
